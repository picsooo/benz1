# Benz Promotion Immobilière — Maquette du site

Maquette de présentation (page d'accueil + page « Appartement témoin ») pour **Benz Promotion Immobilière**, promoteur immobilier à Alger — résidences de haut standing à El Achour, Dely Ibrahim & Chéraga.

## Contenu

- **`index.html`** — page unique, 100 % autonome (polices, images et scripts embarqués). Aucune dépendance externe.

## Aperçu en ligne (GitHub Pages)

1. Dépôt → **Settings** → **Pages**
2. *Build and deployment* → **Deploy from a branch**
3. Branche : **`main`**, dossier : **`/ (root)`** → **Save**
4. Le site sera disponible sur `https://picsooo.github.io/benz1/`
